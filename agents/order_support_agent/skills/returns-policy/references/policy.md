# Northwind return policy (reference)

| Rule | Detail |
|---|---|
| Return window | 30 days from the delivery date. The order's `return_window_closes` field gives the last day. |
| Condition | Unworn, with tags, in original packaging where it had one. |
| Final-sale items | Not returnable, except when damaged or when the wrong item was sent. |
| Before delivery | A return cannot start until the order is delivered; the customer may refuse the parcel instead. |
| Refund method | Original payment method, 5-7 business days after the item reaches the warehouse. |
| Return label | Prepaid label; $6.95 is deducted from the refund unless the return is our fault (damaged, wrong item), when it is free. |
| Restocking fee | 10% of the item price for "no longer needed" returns of items priced $150 or more. No fee for other reasons. |
| Electronics outside the window | Not returnable, but a defect can be claimed under the 12-month warranty at support@northwind.example. |
| Exchanges | Not offered. Return the item and place a new order; shipping on the new order follows the normal rules. |

## Wording

- Rejection: say what rule applied and the alternative, e.g. "That order was delivered 45 days ago and
  returns close after 30, so I can't start a return. The headphones are under a 12-month warranty, so a
  defect can be claimed at support@northwind.example."
- Confirmation question: "Shall I submit this return?" Wait for a clear yes.
